What Is An API?
What Is An API?

Allows for software applications to talk to each other
Android, iPhone, websites can talk to the same system

What Is An API?

What Is An Interface?

HTTP Request Methods
Type of action to be performed
Cannot combine request methods

GET Request	
Used to retrieve (or read) existing data
POST Request
Used to create data
PUT Request
Used to update existing data
PATCH Request
Used to perform partial update of existing data
DELETE Request
Used to remove existing data
Additional Request Methods
HEAD – Used similar to GET, but only some data

API Versioning
Why Use API Versioning?
New features
New data elements
New design
Not backwards compatible
API Version 1.0
Access front doors and trunk with key
API Version 1.1
Access driver door with key
API Version 2.0
Lock and unlock doors, open trunk, and panic alarm with key fob / remote
API Version 2.1
Same as version 2.0
Adds remote start
API Version 3.0
Lock and unlock doors and trunk with door handle button
API Version 3.1
Same as version 3.0
Any doors and trunk
